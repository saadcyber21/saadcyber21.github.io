02 — thesis

The scaffold is the
attack surface nobody tests.

Existing AI red-teaming points attacks at a live model — something you did not write, cannot fix, and pay per run to test non-deterministically. The artefacts you actually own are static: the system prompt is a string, the tool definitions are JSON, the permission logic is code. Static means testable in CI.

    05 — proof lab · runs in your browser

    Don't take the numbers.
    Break them yourself.

    Three of the algorithms documented in these repositories, reimplemented faithfully in JavaScript so they run here with no backend. Same signals, same thresholds, same structural guards — and the same failure modes.

    Reimplementation, not the artefact. The shipped scanner is a single stdlib-only Python file (scanner.py, 56 tests). This is the documented detection logic ported to JS: layer 1 pattern rules, then layer 2 entropy using ratio, coverage and transitions with three structural guards. It also runs the naive entropy > 4.5 test it replaced, side by side, so you can watch that one fail.

          Security issue in one
          of these? Report it
          privately.

          Open a private vulnerability report rather than a public issue — the same courtesy every maintainer of a security tool needs. For anything else, an issue on the relevant repository is fine and usually faster.

          responsible use

          The attack payloads in these repositories are designed to test systems you own. They are deliberately generic and contain no working exploits against third-party services. Do not point them at anything you do not have written authorisation to test.
