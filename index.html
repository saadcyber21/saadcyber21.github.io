§ 05

Verification lab

Run the algorithms in this browser. The lab is a faithful JavaScript reimplementation of the documented detector logic — same signals, same thresholds, same guards — and is labelled as such; it is not the shipped Python artefact.

The calibrated two-layer detector from secret-sweep: pattern rules first, then an entropy layer with three structural guards. Evidence is masked in the output — this page never prints a full token.

    The control plane of zero-trust-ai-gateway: RBAC resolves the role, signature inspection reads the payload, and a refusal is explicit — a 406 with the matched signature — never a silent drop.
